# Abinara Internship Projects

Five projects from the Abinara internship program, covering robotics with ROS, computer vision, C++ and Bash scripting.

| # | Project | What it does | Stack |
|---|---|---|---|
| 1 | [Bash Backup & Restore](Project_1) | Timestamped zip backups of a web app, and a restore script that snapshots the live files before rolling back | Bash |
| 2 | [OOP Friendship Model](Project_2) | `Friend` / `BestFriend` class hierarchy showing inheritance, encapsulation, overriding and static binding | C++ |
| 3 | [3-DOF Arm Inverse Kinematics](Project_3) | Analytic IK solver node for a custom URDF arm, with forward-kinematics error check and Rviz visualisation | ROS Noetic · C++ · URDF |
| 4 | [Hybrid Computer Vision Pipeline](Project_4) | Python node detects shapes and colours with OpenCV and publishes JSON; C++ node draws the detections | ROS Noetic · Python · C++ · OpenCV |
| 5 | [ROS Student Management System](Project_5) | CRUD over ROS services with custom `.srv`/`.msg` types, plus topic-based live updates | ROS Noetic · C++ · Catkin |

Each folder has its own README with setup and run instructions.
